# Spectra media

Screenshots and recordings used by the README and docs on
[`main`](https://github.com/joshmaster2165/spectra). They are kept on this
branch, apart from the code, so installing Spectra doesn't download them.

The docs link to these files by name, so keep the names when replacing one:

```bash
git worktree add ../spectra-media media
# replace the file in ../spectra-media, then commit and push from there
```
